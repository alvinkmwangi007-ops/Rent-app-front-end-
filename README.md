# Rent Desk (front-end)
Static site: open `index.html` or host on GitHub Pages / Netlify.
Demo login while `USE_MOCK` is true: manager / rent2026.
To connect your backend: edit `CONFIG` in `api.js` (set USE_MOCK false, set API_BASE) and delete `mock.js`. The endpoints the backend must provide are listed at the top of `api.js`.
